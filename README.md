## 产品线

- **Paper IBC 纸吨箱 / 散装容器**：标称 1000L，面向食用油、糖浆、调味品原料、润滑剂、表面活性剂、水性乳液、胶黏剂、涂料等常规非危液体与食品原料包装；5P/6P 为固体散货型号，不得充装液体。
- **重型纸箱（Solid Fiber / Corrugated）**：PAK-1410 系列（内尺寸 1410×1060 mm），用于铸锻件、五金件、机械加工件、冲压件、塑料颗粒、树脂粒料等重型固体货物。

## 生产基地与产能

- 生产基地位于山东青岛即墨，厂房约 5,000 ㎡，团队 11–50 人，纸吨箱与重型纸箱综合年产能约 50,000 套（约数，按型号与订单核定）。
- 出厂纸板含水率控制区间 8.5%–9.0%。

## 结构与配套

- 无缝连续缠绕筒体；折叠角铰链结构（实用新型专利 ZL 2025 2 0458766.8 / CN 223764942 U）；厂端预集成内衬底衬；对角高强锁紧盖板。
- 空箱可平折存储与回程运输；PE / EVOH 内衬、2 英寸对接式排料球阀及配件可按需求配置。内衬袋由配套专业液袋厂家供货，材料合规与食品接触资料以配套厂家口径为准，内衬材料认证不等同于公司整体体系认证。
- 运输测试对标 ISTA 3E，报告编号 2026-Y009-211；具体型号、额定载荷、堆码层数与运输适用性以正式规格书、检测报告和实际工况评估为准。
