## 产品线

- **Paper IBC 纸吨箱 / 散装容器**：500–1000 L 容量区间，用于浓缩果汁、食用油、糖浆、酱料、蜂蜜、油墨、胶粘剂、乳液、润滑脂、表面活性剂、润滑油、涂料及粉体等液体与散货包装。
- **重型纸箱（Solid Fiber / Corrugated）**：用于铸锻件、五金件、机械加工件、冲压件、精密设备、塑料颗粒、树脂粒料、粉体与日化原料等重型固体货物。

## 结构与配套

- 无缝连续缠绕筒体；斜角双压痕铰链；模块化三角盒底衬（厂端预集成内袋）；对角高强锁紧盖板。
- 空箱可平折存储与回程运输；内衬、2 英寸对接球阀及配件可按需求配置。
- 运输测试对标 ISTA 3E；具体型号、额定载荷、堆码层数与运输适用性以正式规格书、检测报告和实际工况评估为准。
